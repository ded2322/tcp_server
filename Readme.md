# TCP server c++

This simple tcp server in C++

# Possibilities
This porgramm support multithreading, working only lunux

# Utils
- C++ 17
- Cmake 3.10

# How to start
1. Clone repostiroty

```bash
git clone git@github.com:ded2322/tcp_server.git
```
2. Go to repository and build binary file with `cmake`
```bash
cmake . && make
```
3. Start binary file
```bash
./tcp_server
```
